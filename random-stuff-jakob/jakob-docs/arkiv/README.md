## Lägg till nästa rapport

1. Spara med datum i rätt datummapp och ange källrevision/verifieringstid.
2. För över en bestående förklaring till rätt ämne i systemkartan.
3. Lägg öppna problem i befintlig findings-post eller skapa ett nytt stabilt ID.
4. Lägg en rad i detta index. Behåll originalresultat och länka senare korrigeringar.

Den gemensamma `docs/JOHN-HANDOFF.md`, produktens tekniska guider och
OpenClaws runtimepaket har inte flyttats. Arkivet omfattar endast Jakobs
angivna arbetsrapporter och det tidigare indexet.
