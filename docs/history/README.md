# Historik

Allt i den här mappen är daterad historik från september–oktober 2026: gamla överlämningar, planer, underlag, kvitton och ögonblicksbilder. Filerna flyttades hit oförändrade (utom länkar) med `git mv`, så `git log --follow` visar deras historik.
