Fynd som styr nästa steg

Arbetsordning

  1. Behåll Kevins performance-filer och det verifierade råarkivet.
  2. Fastställ dealer, exakt handling och statuskonflikter i want-listan.
  3. Mappa först en Astrid-gren, exempelvis deal.player.left → box1.
  4. Granska kompletta takes två gånger i följd i den faktiska spelaren.
  5. Låt Kevin granska katalogrevision och integration.
  6. Utöka samma struktur till övriga event och dealers.
192 är planerade variantplatser, inte 192 godkända videor. Tre alternativa inspelningar av samma betydelse kan i stället vara en variant med tre takes.
